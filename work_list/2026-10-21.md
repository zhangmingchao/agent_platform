## 可安装 Python 进程插件

### 已确认的设计

用户批准插件安装、导出、版本管理及 Agent 调用；随后明确要求插件复用现有每用户 Runtime Docker 容器，并允许容器访问网络。插件使用自己的依赖目录，单次调用启动进程。凭据按执行注入，不写入插件包和消息队列。共享容器不提供同用户不同插件之间的安全隔离。
