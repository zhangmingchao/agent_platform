## 工作流结构化字段条件判断

### work_list

1. 定义工作流条件规则与判断结果实体，业务层不直接返回无类型字典。
2. 增加 Agent JSON 输出解析、嵌套字段路径读取和强类型比较能力。
3. 在工作流执行器中接入结构化判断结果，并将实际字段值写入分支追踪事件。
4. 在工作流编辑页面增加字段路径、操作符和期望值配置。
5. 保持关键词、正则和默认分支的历史配置兼容。
6. 增加单元测试和配置说明文档，并执行后端回归与前端构建检查。

### 实现方案

- 使用 `WorkflowConditionRule` 表示单条规则，使用 `WorkflowConditionResult` 表示命中结果。
- 结构化 Agent 的输出在条件节点执行时解析为 JSON，仅在本次判断中解析一次。
- 使用点号路径读取嵌套对象和数组，如 `result.level`、`items.0.name`。
- 等值操作同时比较 JSON 类型和值，防止将 `true` 与 `1` 错误视为相等。
- 无法解析 JSON、字段缺失或类型不支持比较时，该规则不命中并继续判断后续规则。
